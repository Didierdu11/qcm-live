Mode d’emploi QCM Live

1. Créer un QCM

Dans Mes QCM, clique sur + Nouveau QCM.

2. Importer Excel

Clique sur Importer Excel et sélectionne un fichier .xlsx, .xls ou .xlsm.

3. Colonnes Excel

Colonnes A à L : Question, Réponses A-D, Bonnes réponses, Note partielle, Nombre bonnes réponses, Points partiels, Titre, Description, Explication.

4. Lancer une session

Clique sur Lancer pour générer un code et un QR code.

5. Participation

Le participant saisit son nom, répond aux questions et voit « Question X sur Y ».

6. Résultats

À la fin, le participant voit son score. Le présentateur peut télécharger le rapport PDF.
